# The Tired Dark Lord: A 100-Word Villain Monologue

Entry for the make.fun bounty
`u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb`.

`main.ts` writes one monologue of exactly 100 words to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The speaker is a dark lord who has held
his mountain for forty years and is receiving the hero at the door. His
tiredness is never stated — it lives in the crooked banners no one fixes,
the sword stuck in the door since Tuesday, the ravens that stopped coming,
and a midnight ritual that can wait one more night. The sting lands in the
last line: the kingdom gets ruined tomorrow.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
