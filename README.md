A 100-word villain monologue: a dark lord, forty years on his mountain, receiving the hero at the door — and putting the apocalypse off until tomorrow. His tiredness is never stated; it lives in the crooked banners no one fixes, the sword stuck in the door since Tuesday, and a midnight ritual that can wait one more night.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` writes the monologue (exactly 100 words, 544 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
